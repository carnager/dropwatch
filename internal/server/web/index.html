How this works

Release groups (about 1 GB) list every album, EP and single. Each check updates your artists' discographies and raises notifications for new and upcoming releases; a new artist's first check announces its releases from the last 30 days. The latest dump is kept, so syncs can recognize new artists without asking MusicBrainz. MusicBrainz publishes on Wednesdays and Saturdays, so the following mornings are good check days. Versions already processed aren't downloaded again.

Release titles (about 21 GB) list every edition of every album. They let albums tagged with a release ID (Subsonic, melody) and reissue-titled rips match exactly. The download streams through without being stored; only titles for albums already in dropwatch are kept.

Dropwatch must be running at the scheduled time; a missed check runs once on the next start, and a failed one retries at the next scheduled time. Use a named timezone such as Europe/Berlin to follow daylight saving time; “Local” is the server's timezone.

ntfy

Types

Subscribe to the topic in the ntfy app. New releases are pushed when a dump check finds them, release-day reminders at midnight; up to five come one by one, more as one summary. Releases you own or ignore are skipped. Turning this on doesn't send notifications you already have.

Anyone who knows a topic name on ntfy.sh can read it, so pick one that's hard to guess, or use your own server with an access token. With “Link to” set, tapping a push opens the release in dropwatch.
